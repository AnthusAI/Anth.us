## The other 2026 trend

Cheap coding is one story. The other is remote. Every coding-agent product added it this year. Cursor. Claude Code (not "Cloud Code"). Codex. Antigravity. Five if you count Grok Bot.

## What remote actually means

Compute on a machine that is not the laptop in front of you. Check in from a phone or a web page. Sometimes from another IDE on another computer.

Every system does this differently. An hour to unpack the differences. Do not pretend they are the same feature.

## Grok Bot is the fifth

Framing to record. Verify. Do not invent acquisition details.

Grok Bot from the Cursor company after the xAI acquisition. Built from the ground up as a remote agent system, not a coding agent with remote tacked on. It exists in the cloud. It notifies you on any device. Easier to set up. Easier to run in the background. You do not think about where the compute runs.

That is the next stage of remote agent: more autonomy behind the scenes. Explicitly good at that at the expense of not being a good computing system. Details of that failure belong in the [Grok Bot review](/blog/a-week-with-grok-bot/).

## What this article holds

This piece compares all five. It holds the feature comparison chart: obedience, scheduling, cloud background, persistence without a Mac Mini or a lid-open laptop, hopper vs actor, cheap-model leverage. The Grok Bot review points here.

## The memory bus

The five systems do not share a working tree. They can still collaborate if they share a memory system. An information bus. [Kanbus](https://kanb.us/) is one: git as the bus, issues as the messages. It is not the only one. Jira works if every agent can see it. Any shared tracker works if every agent platform can read and write it: the ones on your laptop, the ones in someone else's cloud, Grok Bot in its isolated computer.

Then Grok Bot can be the secretary. A note-taking agent files an assignment. A trusted coding agent on another agent platform picks it up and does the change. You use Grok Bot for what it is good at: ever-present, ubiquitous, notes. You do not use it for the work. The bus is the handoff.
