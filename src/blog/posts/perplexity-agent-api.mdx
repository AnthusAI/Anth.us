[Perplexity's Agent API](https://www.perplexity.ai/hub/blog/agent-api-a-managed-runtime-for-agentic-workflows) is a managed runtime for the agent loop: search, tool execution, reasoning, and multi-model fallback, one endpoint and one key. They say it replaces a model router, a search layer, an embeddings provider, a sandbox, and a monitoring stack. Built-in `web_search` and `fetch_url`, plus your own functions.

Everybody has an agent platform these days.
