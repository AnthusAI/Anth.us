## What it is

Biblicus is a file-first corpus and retrieval system. It treats the filesystem as the source of truth, then layers extraction, indexing, retrieval, and analysis on top so agent workflows can work from inspectable evidence instead of opaque black boxes.

## What it does

- Ingests notes, files, URLs, and crawled sites into structured corpora.
- Runs pluggable extraction pipelines over PDFs, OCR, speech, and other inputs.
- Builds retrieval backends and context packs for RAG-style workloads.
- Supports reinforcement-memory style analysis over timestamped human feedback and notes.

## Why it matters

Knowledge systems get fragile when the data model is hidden behind vendor-specific storage and magical retrieval behavior. Biblicus keeps the corpus legible, rebuildable, and easy to evolve as extraction and retrieval techniques change.

## How it fits the Anthus Platform

Biblicus provides the knowledge substrate for the platform. [Tactus](/platform/tactus) can use it to ground procedures in evidence. [Plexus](/platform/plexus) can consume feedback-oriented analysis. [Caducus](/platform/caducus) can use its semantic clustering and memory concepts to make noisy operational data more useful.

A common pattern is [Biblicus](/platform/biblicus) + [Tactus](/platform/tactus) + [Babulus](/platform/babulus): curate the source corpus, define the extraction or analysis procedure, then turn the result into content or video output.
