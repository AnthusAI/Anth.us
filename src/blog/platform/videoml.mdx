## What it is

VideoML is the code-first media pipeline behind Anthus's programmable video work. It turns authored source into scripts, timelines, audio, and rendered outputs so explainers, demos, and marketing assets can move through reproducible workflows instead of staying trapped in manual editing tools.

## What it does

- Generates script, timeline, and audio artifacts from declarative source.
- Supports end-to-end media pipelines from generation through render.
- Integrates with browser bundles and player components for previews.
- Provides the rendering substrate that higher-level tools can build on.

## Why it matters

Video is increasingly part of product delivery, documentation, and go-to-market work. Anthus wants to treat that medium with the same rigor as software: versioned inputs, deterministic outputs, automated rendering, and repeatable review loops.

## How it fits the Anthus Platform

VideoML is the media substrate that powers [Babulus](/platform/babulus). On the site, it deserves its own page because it helps explain that the Anthus Platform is not only about agent infrastructure; it is also about extending software discipline into adjacent operational workflows like communications and marketing.

A common pattern is [Biblicus](/platform/biblicus) + [Babulus](/platform/babulus) + [VideoML](/platform/videoml): ground the source material, script the narrative, and render deterministic media assets from the same pipeline.
