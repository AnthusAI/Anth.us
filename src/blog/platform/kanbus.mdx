## What it is

Kanbus is an issue tracker and planning system designed for a world where humans and AI agents collaborate directly in source-controlled workflows. Issues live as files in the repo, which keeps project memory portable, auditable, and easy for agents to read and update.

## What it does

- Stores work items as plain files instead of locking them in a hosted task database.
- Exposes issue and planning workflows through CLIs and a local web console.
- Supports wiki-style project views that summarize live issue data.
- Uses vocabulary and structures that map cleanly to both human planning and LLM reasoning.

## Why it matters

AI-agent orchestration needs durable work memory. If the tasks, notes, and status are trapped in a separate SaaS system, the engineering loop gets brittle. Kanbus keeps the work artifacts near the code and makes agent collaboration much easier to govern.

## How it fits the Anthus Platform

Kanbus is the workload-orchestration layer for the broader platform. It complements [Tactus](/platform/tactus) by giving procedures a place in an actual delivery workflow, and it complements [Plexus](/platform/plexus) by turning evaluation and platform work into a manageable operating cadence.

A common pattern is [Kanbus](/platform/kanbus) + [Tactus](/platform/tactus) + [Plexus](/platform/plexus): track the work, run the procedure, and keep the quality loop visible over time.
